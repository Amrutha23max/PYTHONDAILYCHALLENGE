 Smart Transaction Risk Detector

Problem
Analyze daily transactions, classify them, and detect suspicious patterns to determine a risk level.

 Approach
- Used a dictionary to categorize transactions  
- Applied conditions using a loop  
- Used list comprehension to filter valid transactions  
- Calculated total amount and count  
- Determined risk based on patterns  

 Personalization
- High Risk if high-risk transactions ≥ (2 + X)  
- Large Spending if total > (5000 + X × 100)  

 Output
- Categorized transactions  
- Total amount  
- Number of transactions  
- Final risk level (Low / Moderate / High)  

 Learning
Improved understanding of loops, conditions, dictionaries, and basic problem solving in Python.
